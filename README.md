# NoKap HQ

La home del team NoKap: https://nokapmngmt.netlify.app

- `index.html` – il sito (attività, scadenze, testi & editoria, caricamento file su Drive, moodboard, link, brand kit, team).
- `firebase-config.js` – collegamento al progetto Firebase `nokap-hq` (valori pubblici, non password).
- `firestore.rules` – regole di accesso al database (copia di quelle pubblicate in Firebase).
- `seed.json` – dati iniziali.
- `GUIDA.md` – come è stato configurato tutto.

Ogni modifica caricata qui va online da sola su Netlify.
